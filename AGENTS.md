# AGENTS.md — mob_whisper

Offline speech-to-text plugin for Mob: whisper.cpp (vendored, CPU-only) as a
`MobSpeech.Engine`. Also read `~/code/mob/AGENTS.md` and `~/AGENTS.md`.

- `c_src/mob_whisper_nif.cpp` — NIF (`cpp_archive`, needs mob_dev ≥ 0.7.12).
  Transcription runs on a native thread and replies `{:mob_whisper_result, ref, result}`
  (Mob BEAMs have ONE dirty CPU and ONE dirty IO scheduler; don't block them).
- `c_src/capture_android.cpp` (AAudio via dlopen), `c_src/capture_ios.mm`
  (AudioQueue, manual retain/release — iOS is NOT device-verified yet).
- `c_src/whisper.cpp/` is generated by `scripts/vendor_whisper.sh <tag>`; don't
  hand-edit. `c_src/ggml_arch_*` pick ARM/x86 kernels per ABI.
- `lib/mob_whisper/server.ex` — the session/model state machine; tested with
  `test/support/fake_native.ex` (`config/config.exs`, test env only).
- Don't declare `NSMicrophoneUsageDescription` (core owns it; plist collision).
- Local deps: `MOB_SPEECH_PATH` / `MOB_DEV_PATH` env vars in `mix.exs`.
- Device proof recipe: a host app with this plugin, RPC `MobWhisper.start(self(), [])`,
  `say -v Samantha` from the Mac next to the phone, `MobWhisper.stop(self())`,
  read `MobWhisper.status().last` for timings.
- Gate: `mix test`, `mix format --check-formatted`, `mix credo --strict`,
  `mix compile --warnings-as-errors`.
